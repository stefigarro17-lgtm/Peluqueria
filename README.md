# 💇 PeluIA — Sistema Integral de Gestión Inteligente para Peluquería

## 📋 Descripción

**PeluIA** es una aplicación integral para la gestión de peluquerías que aprovecha múltiples **Agentes de Inteligencia Artificial** para automatizar y optimizar las operaciones diarias del negocio.

### 🔍 Problema a resolver

Las peluquerías enfrentan desafíos operativos que consumen tiempo y recursos:

- **Gestión de turnos ineficiente**: cancelaciones de último momento, superposición de horarios y falta de recordatorios que generan pérdidas económicas.
- **Atención al cliente limitada**: consultas repetitivas sobre servicios, precios y disponibilidad que saturan al personal durante el horario de trabajo.
- **Falta de personalización**: los clientes no reciben recomendaciones basadas en su historial, tipo de cabello o tendencias actuales.
- **Descontrol de inventario**: productos que se agotan sin aviso previo y compras no planificadas que afectan la rentabilidad.

### 🤖 Rol de los Agentes de IA

El sistema cuenta con **4 agentes especializados** que trabajan de forma coordinada:

| Agente | Función | Valor Agregado vs. Solución Tradicional |
|--------|---------|----------------------------------------|
| **Agente de Turnos** | Gestiona reservas, cancelaciones y reprogramaciones automáticamente. Envía recordatorios inteligentes. | Elimina la agenda manual y reduce las ausencias con recordatorios adaptativos basados en el comportamiento del cliente. |
| **Agente de Atención al Cliente** | Responde consultas sobre servicios, precios, disponibilidad y ubicación en lenguaje natural. | Disponible 24/7, responde instantáneamente sin ocupar al personal. Aprende de las preguntas frecuentes. |
| **Agente de Recomendación de Estilos** | Sugiere cortes, colores y tratamientos según el perfil del cliente, historial y tendencias. | Ofrece personalización imposible de escalar manualmente, basada en análisis de datos y tendencias actuales. |
| **Agente de Inventario** | Monitorea el stock en tiempo real, predice la demanda y genera alertas de reposición. | Anticipa necesidades con predicción de demanda, evitando quiebres de stock y sobrecompras. |

### ✨ Valor Agregado de la IA

A diferencia de una solución tradicional (agenda en papel, planilla Excel, atención telefónica), PeluIA:

- **Automatiza** tareas repetitivas, liberando al profesional para enfocarse en su trabajo.
- **Aprende** del comportamiento de los clientes para mejorar las sugerencias.
- **Predice** demanda y tendencias, permitiendo una toma de decisiones proactiva.
- **Escala** sin necesidad de contratar personal adicional para tareas administrativas.

## 🛠️ Entorno y Requisitos

### Requisitos del Sistema

- **Sistema Operativo**: Linux (Ubuntu/Debian), macOS o Windows
- **Node.js**: v18 o superior
- **Git**: v2.x o superior
- **Navegador**: Chrome, Firefox o Edge (última versión)

### Instalación de la IDE Google Antigravity

1. Descargar la IDE Google Antigravity desde el sitio oficial.
2. Instalar la aplicación siguiendo el instalador para tu sistema operativo.
3. Abrir Antigravity e iniciar sesión con tu cuenta de Google.

### Clonar el Repositorio

```bash
git clone https://github.com/<tu-usuario>/pelu.git
cd pelu
```

### Instalar Dependencias

```bash
npm install
```

### Ejecutar el Proyecto

```bash
npm run dev
```

> El servidor de desarrollo se iniciará en `http://localhost:5173` (o el puerto que se indique en la consola).
